# 雨夜便利店街角 · Rainy Night Konbini Corner

一个用 Three.js 做的三渲二（cel shading）微缩场景：雨夜里的日式便利店街角。
整页只有一个全屏 canvas，没有任何 UI 元素，用鼠标拖拽旋转、滚轮缩放即可观察这个"可收藏的小模型"。

## 开始

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址即可。

| 命令 | 说明 |
|------|------|
| `npm run dev` | 开发服务器 |
| `npm run build` | 构建生产包 |
| `npm run preview` | 预览构建结果 |

## 场景说明

- **底座**：22×22 的正方形基座，所有内容都搭在上面；街道在 +X / +Z 方向转角，便利店位于视觉中心。
- **室外**：招牌灯箱、玻璃橱窗、自动门、屋檐雨棚、地垫、雨伞架、分类垃圾桶、自动贩卖机、自行车、
  路灯、电线杆与电线、路牌、护栏、车挡、停车位、排水沟与格栅、井盖、反光斑马线、导盲砖、
  公告栏、小巷入口（含空调外机、周转箱、垃圾箱）、店后围栏杂物。
- **室内**：透过大面积玻璃可见整齐货架、饮料冷柜、便当饭团陈列柜、收银台（收银机 / 咖啡机 / 关东煮 /
  热食柜 / 香烟架 / 灯箱菜单）、杂志架、冰淇淋冰柜、内用吧台与高脚凳、地面导视、储物柜与后场门。
- **动效**：持续降雨、屋檐滴水与落地水花、地面积水波纹、招牌与灯箱轻微闪烁、自动门定时开合、
  雨水沿玻璃滑落、湿路面反射霓虹灯光、远处交通信号灯循环变化。

## 代码结构

```
src/
  main.js               渲染器 / 相机 / OrbitControls / 主循环
  core/
    pipeline.js         深度 + 法线边缘检测的描边后处理管线
    materials.js        toon 材质、发光贴片、程序化海报与货品贴图
    palette.js          夜景配色
    layers.js           特效层（描边 pass 会跳过这一层）
    optimize.js         同材质静态网格合批
  world/
    index.js            场景组装、灯光、天空渐变
    layout.js           街区尺寸与各建筑占位
    base.js             底座、路面、人行道、路面标线、排水沟、停车位
    store.js            便利店主体、玻璃、雨棚、招牌、自动门、灯光溢出
    interior.js         店内陈设
    props.js            街道道具
    neighbors.js        周边建筑与远景
  effects/
    rain.js             降雨粒子
    puddles.js          湿地面反射与雨滴涟漪
    drips.js            屋檐滴水
    glassRain.js        玻璃上的雨痕
```

## 已知限制

- 描边用的是屏幕空间深度 + 法线检测，非常细的物体（电线、栏杆）在低分辨率下描边可能变淡。
- 反射是着色器伪造的光源拉伸，不是真实反射，光源上限为 8 个（按亮度取前 8）。
- 阴影贴图只在启动的前几帧更新（场景是静态的），自动门开合不会改变阴影。
